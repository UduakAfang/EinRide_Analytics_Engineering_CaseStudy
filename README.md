# EinRide_Analytics_Engineering_CaseStudy
 Case study of analytics engineering: building a pipeline, staging on DBT, storing the data in the lakehouse. We'll be using Databricks for this project. 

Public project demonstrating a case study of analytics engineering for EinRide. This will store historical data. We'll pull the historical data from GitHub, as well as the mapping data and the config files. Go through the entire process of streaming data with Azure, the bronze stage layer of BigTable staging in DBT, and all of the other processes.
